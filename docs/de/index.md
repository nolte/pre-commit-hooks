## Wo anfangen

- **Einen Hook einbinden.** Das Repository in die
  `.pre-commit-config.yaml` eines Konsumenten eintragen, einen Tag pinnen,
  den Integration-Branch konfigurieren. Beginne mit
  [Erste Schritte](getting-started/index.md) und öffne dann die Hook-Seite
  unter [Referenzen → Hooks](references/index.md).
- **Beitragen.** Einen Hook hinzufügen, einen bestehenden ändern oder die
  gerenderte Doku aktualisieren. Lies
  [Anleitungen → Mitwirken](guides/contributing.md).
- **Konformität prüfen.** Bestätigen, dass das Repository die
  Portfolio-Specs weiterhin erfüllt (Projektstruktur, Release-Automation,
  Renovate, Vale). Lies
  [Referenzen → Governance und Specs](references/governance.md).
