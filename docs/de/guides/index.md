# Anleitungen

Aufgabenorientierte How-tos für Mitwirkende. Jede Anleitung setzt eine
Leserin voraus, die die Grundlagen bereits aus
[Erste Schritte](../getting-started/index.md) oder den
[Hook-Referenzen](../references/index.md) kennt.

## Verfügbare Anleitungen

- [Mitwirken](contributing.md): einen Hook hinzufügen, einen bestehenden
  ändern oder die gerenderte Doku aktualisieren. Behandelt
  Hook-Konventionen, den Selbsttest-Vertrag, lokale Checks und den
  Pull-Request-Ablauf.

Die Liste ist bewusst kurz. Das Repository ist klein, und die meisten
Fragen von Mitwirkenden lösen sich über
[`CLAUDE.md`](https://github.com/nolte/pre-commit-hooks/blob/main/CLAUDE.md)
oder den Abschnitt [Referenzen](../references/index.md).
