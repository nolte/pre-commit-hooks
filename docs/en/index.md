## Where to start

- **Adopt a hook.** Wire the repository into a consumer's
  `.pre-commit-config.yaml`, pin a tag, configure the integration branch.
  Start with [Getting Started](getting-started/index.md), then open the
  hook page under [References → Hooks](references/index.md).
- **Contribute back.** Add a hook, change an existing one, or update the
  rendered docs. Read [Guides → Contributing](guides/contributing.md).
- **Verify conformance.** Confirm the repository still satisfies the
  portfolio specs (project structure, release automation, Renovate, Vale).
  Read [References → Governance and specs](references/governance.md).
