# Guides

Task-oriented how-tos for contributors. Each guide assumes a reader who
already knows the basics from
[Getting Started](../getting-started/index.md) or the
[hook references](../references/index.md).

## Available guides

- [Contributing](contributing.md): add a hook, change an existing one, or
  update the rendered docs. Covers hook conventions, the self-test
  contract, local checks, and the pull-request flow.

The list is intentionally short. The repository is small, and most
contributor questions resolve via
[`CLAUDE.md`](https://github.com/nolte/pre-commit-hooks/blob/main/CLAUDE.md)
or the [References](../references/index.md) section.
